# Картинки экранов (опционально)

Бот работает и без единой картинки — экраны без файла отправляются обычным текстом.
Чтобы включить фирменные картинки, положите сюда 7 файлов со следующими именами
(см. `IMAGES` в `handlers/ui_screens.py`, имена можно поменять там же):

| Файл                 | Экран                                  |
|----------------------|-----------------------------------------|
| `start.png`          | Стартовое меню (`/start`)              |
| `buy.png`             | Купить / продлить подписку             |
| `tariffs.png`         | Выбор тарифа                           |
| `payment.png`         | Окно оплаты                            |
| `subscriptions.png`   | Мои подписки                           |
| `info.png`            | Информация                             |
| `referral.png`        | Пригласить друга                       |

Рекомендуемый формат — PNG/JPG, соотношение сторон близкое к 4:3 или 1:1.
