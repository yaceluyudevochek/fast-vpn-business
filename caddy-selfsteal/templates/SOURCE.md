# Источник шаблонов

Эти 11 HTML-шаблонов маскировки (SNI templates) взяты без изменений из проекта
[Case211/remnanode-install](https://github.com/Case211/remnanode-install)
(раздел `sni-templates/`), распространяемого по лицензии MIT.

Используются как есть — для "decoy"-сайта, который Caddy Selfsteal отдаёт
вместо настоящего Reality-туннеля при обращении не через Xray-клиент.

Смотрите `README.md` внутри каждого шаблона (если есть) для деталей самого шаблона.
